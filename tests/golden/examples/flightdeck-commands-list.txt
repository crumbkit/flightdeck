PATH                              ABOUT
flightdeck                        Start a local web page for a crumbkit tool
flightdeck open                   Open a local web page of the mxv workspaces and a tool's commands
flightdeck workspaces             Read the local mxv workspaces
flightdeck workspaces list        List the local mxv workspaces with their units, routes and ports
flightdeck workspaces show        Show one local mxv workspace with its checkouts and units
flightdeck compliance             Fetch the repositories' rules reports and build the compliance document
flightdeck compliance build       Join each repository's rules report into one compliance document
flightdeck compliance fetch       Download each repository's newest rules report from its GitHub runs
flightdeck commands               Explore flightdeck's commands
flightdeck commands list          List a branch of flightdeck's commands with their arguments, examples and columns
flightdeck skills                 Give coding agents flightdeck's skill
flightdeck skills install         Install flightdeck's skills into each agent skills directory that exists
flightdeck skills check           Check that each installed copy of flightdeck's skills matches this flightdeck
flightdeck skills print           Print flightdeck's skill
flightdeck completion             Set up flightdeck's completion in a shell
flightdeck completion install     Install flightdeck's completion where the shell loads it
flightdeck completion check       Check that flightdeck's installed completion file matches this flightdeck
flightdeck completion print       Print flightdeck's completion registration script for a shell
flightdeck schemas                Explore the JSON documents that flightdeck prints
flightdeck schemas list           List the JSON documents that flightdeck prints, with a description of each
flightdeck schemas show           Print the JSON Schema of each document
flightdeck self                   Review flightdeck itself
flightdeck self environment       Explore the environment variables that flightdeck reads
flightdeck self environment list  List the variables that flightdeck and crumbkit read, with their rules and values
