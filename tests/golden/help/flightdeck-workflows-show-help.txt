Show one workflow graph with its problems, live records and freshness

Usage: flightdeck workflows show [OPTIONS] <SLUG>

Arguments:
  <SLUG>
          The graph's slug, as `flightdeck workflows list` prints it

Options:
      --json
          Print the result as a JSON document. The default prints text.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  flightdeck workflows show development-flow --json
          Print the document that the Workflows page draws for the development flow

Effects: read-only, closed-world.
