Start a local web page for a crumbkit tool

Usage: flightdeck [OPTIONS] <COMMAND>

Verbs
  open        Open a local web page that lists and runs a tool's commands

Commands
  commands    Explore flightdeck's commands
  skills      Give coding agents flightdeck's skill
  completion  Set up flightdeck's completion in a shell
  schemas     Explore the JSON documents that flightdeck prints

Options:
  -h, --help     Print help (see more with '--help')
  -V, --version  Print version

Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `flightdeck --help` describes them.
Topics: exit-codes. `flightdeck help <TOPIC>` prints one.
Next: flightdeck <COMMAND> -h
