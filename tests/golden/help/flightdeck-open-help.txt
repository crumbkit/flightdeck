Open a local web page that lists and runs a tool's commands

Usage: flightdeck open [OPTIONS] <TOOL>

Arguments:
  <TOOL>
          The crumbkit tool, by a name on PATH or a path

Options:
      --read-only
          Run only the tool's read-only commands from the page

      --no-browser
          Print the path of the page to open instead of opening the browser

      --json
          Print the result as a JSON document. The default prints text.

  -h, --help
          Print help (see a summary with '-h')

Examples:
  flightdeck open shelf
          Open the page for shelf in the browser

  flightdeck open ./target/debug/shelf --read-only --no-browser
          Serve a built shelf's read-only commands and print the page to open

Effects: read-only, open-world.
Output: no result on standard output, and --json prints a failure as JSON.
