List a branch of flightdeck's commands with their arguments, examples and columns

Usage: flightdeck commands list [OPTIONS] [PATH]...

Arguments:
  [PATH]...  The names of the commands below the root that lead to the branch, such as `books list`

Options:
      --limit <N>  Print at most this many rows [default: 25]
      --all        Print every row
  -h, --help       Print help (see more with '--help')

Examples:
  flightdeck commands list
  flightdeck commands list commands list --json --full

Effects: read-only, closed-world.
Global flags: --json, --fields <FIELD>, --full, --no-input. `flightdeck commands list --help` describes them.
Next: flightdeck commands list --help explains each column.
