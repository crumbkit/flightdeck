Explore the JSON documents that flightdeck prints

Usage: flightdeck schemas [OPTIONS] <COMMAND>

Commands:
  list  List the JSON documents that flightdeck prints, with a description of each
  show  Print the JSON Schema of each document

Options:
  -h, --help  Print help (see more with '--help')

Global flags: --json, --fields <FIELD>, --long, --full. `flightdeck schemas --help` describes them.
Next: flightdeck schemas <COMMAND> -h
