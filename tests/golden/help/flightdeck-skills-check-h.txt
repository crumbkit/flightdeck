Check that each installed copy of flightdeck's skill matches this flightdeck

Usage: flightdeck skills check [OPTIONS]

Options:
      --dir <DIR>  Check this skills directory in place of the agent skills directories
  -h, --help       Print help (see more with '--help')

Examples:
  flightdeck skills check

Effects: read-only, closed-world.
Rows: the default text lists only the rows that report a problem, and --long, --fields or --json lists every row.
Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `flightdeck skills check --help` describes them.
Next: flightdeck skills check --help explains each column.
